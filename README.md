# Driven by Data: Decoding Automobile Purchase Behavior

## Project Overview
This project explores customer purchase behavior in the automobile industry using Python and business analytics.

## Business Questions Answered
- Do men prefer SUVs more than women?
- What is the likelihood of salaried individuals buying sedans?
- Does partner income influence premium car purchases?
- How do loans impact automobile spending?

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statistical Analysis

## Key Insights
- Women showed higher SUV purchase behavior.
- Salaried buyers had a 44.4% sedan purchase probability.
- Dual-income households showed higher premium vehicle spending.
